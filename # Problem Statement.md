# Problem Statement

Traditional visitor management systems often depend on manual registers
to record visitor details. This process is time-consuming and can lead
to incorrect entries, duplicate records, and difficulty in searching
previous visitor information.

The Visitor Management System is a web-based application developed using
Python Flask and MySQL. It allows authorized users to register visitors,
store their details securely, generate gate passes, and search visitor
history.

The system reduces paperwork, improves visitor tracking, and provides
quick and organized access to visitor information.
