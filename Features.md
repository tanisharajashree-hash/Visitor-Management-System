# Features

## Visitor Management System

The system provides the following simple features:

### 1. Admin Login
- Admin can login using username and password.
- Only authorized admin can access the system.

### 2. Visitor Registration
- Add new visitor details.
- Store visitor name, phone number, email and address.
- Store ID proof and purpose of visit.

### 3. Visitor Search
- Search for a visitor using Visitor ID or name.
- View the visitor's basic details.

### 4. Gate Pass Management
- Generate a gate pass for a registered visitor.
- Store pass ID, issue date and status.

### 5. Visit Entry and Exit
- Record visitor entry time.
- Record visitor exit time.
- Store the visit date.

### 6. Visit History
- View previous visit details.
- Display entry time, exit time and purpose of visit.

### 7. Simple Data Management
- Add, view, search and update visitor information.
- Keep the system simple and easy to use.
